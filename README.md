# Hackfinity
A simple web project built during my first college hackathon. This simulator demonstrates how traffic lights work using HTML, CSS, and JavaScript. It’s an interactive way to learn about DOM manipulation, styling, and basic animations.
✨ Features
- 🟢 Green, Yellow, Red lights with realistic timing
- ⏱️ Automatic light switching using JavaScript intervals
- 🎨 Styled with CSS for a clean, modern look
- 💻 Responsive design that works on desktop and mobile
- 🖱️ Option to start/stop the simulation with a button

🛠️ Tech Stack
- HTML5 → Structure of the traffic lights
- CSS3 → Styling and layout of the lights
- JavaScript (ES6) → Logic for light changes and timing

🚀 How to Run
- Clone the repository:
git clone https://github.com/your-username/traffic-light-simulator.git
- Navigate to the project folder:
cd traffic-light-simulator
- Open index.html in your browser.

🎯 Learning Outcomes
- Practiced DOM manipulation
- Learned CSS positioning and styling
- Implemented JavaScript timers (setInterval)
- Gained experience working on a project in a hackathon setting
